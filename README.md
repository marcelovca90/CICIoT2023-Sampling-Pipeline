# A Sample-Based, Multi-Stage Machine Learning Pipeline for Scalable IoT Threat Detection (MQTT_IoT_IDS2020)

### Setup

```
conda create -n "MQTT_IoT_IDS2020-Sampling-Pipeline" python=3.11
conda activate MQTT_IoT_IDS2020-Sampling-Pipeline
pip install -r requirements.txt
```

### Execution

```
jupyter lab
- For a single experiment: pipeline_code.ipynb
- For multiple experiments: pipeline_runner.ipynb
```
